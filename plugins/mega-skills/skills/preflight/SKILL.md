# Preflight окружения

Выполнить проверки по порядку. Что можно — исправить, что нельзя — сразу сообщить пользователю, а не повторять попытки вслепую. В конце вывести таблицу статусов.

## Проверки

1. **Docker / OrbStack**
   `docker info >/dev/null 2>&1`. Если не отвечает — `open -a OrbStack` (или Docker Desktop), подождать до 60 секунд. Не поднялся — остановиться и сказать об этом.

2. **Переменные в .env**
   Найти неподставленные значения: `grep -nE '\$\{[A-Z_]+\}' .env .env.testing 2>/dev/null`.
   Особенно `APP_URL`: тесты запускать с явным значением, например `APP_URL=http://localhost php vendor/bin/phpunit`. 404 в тестах почти всегда означает неверный APP_URL, а не баг роутинга.

3. **Смонтированный worktree**
   Если тесты идут в контейнере, сравнить путь bind mount с текущим: `docker inspect <container> --format '{{range .Mounts}}{{.Source}} {{end}}'` и `git rev-parse --show-toplevel`. Не совпадает — пересоздать контейнер для текущего worktree, иначе результаты тестов недостоверны.

4. **Изоляция тестовой БД**
   Тестовую БД могут использовать параллельные сессии Claude. Для отдельной задачи использовать уникальный `COMPOSE_PROJECT_NAME` (например `pr-<номер>`) или отдельное имя БД по ветке. При кратковременных ошибках блокировок — сначала перезапустить тест, потом отлаживать.
   Пароли БД передавать через переменные окружения контейнера, а не через экранирование в shell.

5. **MariaDB / MySQL**
   Если тестам нужна БД, а локальной нет — поднять одноразовый контейнер `mariadb` с портом и паролем из `.env.testing`.

6. **Фронтенд-ассеты**
   Если тесты или страницы требуют Vite-сборки и нет `public/build/manifest.json` — выполнить `npm run build`.

7. **Composer autoload**
   Проверить, что пути в `vendor/composer/autoload_psr4.php` указывают на текущий worktree. Если классы подтягиваются из другой копии репозитория — выполнить `composer dump-autoload`.

8. **BSD sed на macOS**
   В скриптах использовать `sed -i ''` или переносимые альтернативы (perl, python), не GNU-синтаксис `sed -i`.

## Итог

```
Проверка            Статус   Комментарий
Docker              OK
.env / APP_URL      FIXED    APP_URL задан явно
Worktree mount      OK
Тестовая БД         OK       COMPOSE_PROJECT_NAME=pr-2989
...
```

Если встретился новый тип сбоя окружения, которого нет в списке, — предложить пользователю добавить его в этот скилл.
